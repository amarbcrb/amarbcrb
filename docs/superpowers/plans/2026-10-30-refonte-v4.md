# Refonte v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the v4 spec: Inter Tight font, auto framing, faster first load, media library with link, GIF and video, on-site editing, light admin with custom tabs, password-protected folders.

**Architecture:** Static site with native ES modules and no build step. Content stays one JSON in Drive, read and written by the Apps Script (already shipped in 57bf8f4). Rendering stays in `render.js` and `cartes.js`. It gains `data-edit`, `data-element` and `data-ajout` marks, used only by lazily imported editing modules under `assets/edition/`. Media rendering is centralised in `assets/media.js`.

**Tech Stack:** Vanilla JS modules, CSS, Google Apps Script. Tests use `node --test` and Playwright, with `tests/helpers.mjs`, the fake script `tests/mock-script.mjs` and the GAS fakes.

**Spec:** `docs/superpowers/specs/2026-10-30-refonte-v4-design.md`

## Global Constraints

- **No build:** `.js` files are served as is. No new runtime dependency.
- **Safe rendering:** all content text goes through `el()` (`assets/dom.js`). `html:` is reserved for SVG constants. Every `href` and `src` goes through `lienSur` or the `/…` filter.
- **Wording:** French UI text, short sentences. No em-dash in UI copy.
- **Accessibility (WCAG 2.2 AA):** touch targets at least 44 px, text contrast at least 4.5:1, visible focus, accessible names. `tests/ux.test.mjs` must stay green and cover the new screens.
- **Motion:** respect `prefers-reduced-motion`. Under reduced motion there is no autoplay video and no automatic carousel movement.
- **Layout:** no horizontal overflow at 320, 390 and 1366 px, in light and dark.
- **Lazy editing code:** a visitor never requests anything under `assets/edition/`.
- **Script API:** the Apps Script API is frozen by 57bf8f4. `tests/mock-script.mjs` mirrors every endpoint the site uses.
- **Protected folders:** the public content never holds folder passwords, folder links or protected file lists.

## Review Focus

1. **Visitor network:** a visitor's network log never contains `assets/edition/`. Test: Task 7, `visiteur : aucun module d'édition chargé`.
2. **Draft isolation:** the draft only lives on the owner's device, and a reload in edit mode keeps it. Visitors and the owner outside edit mode see the published content. Test: Task 7, `brouillon : gardé au rechargement, invisible hors édition`.
3. **Pasted text and links:** pasted rich text becomes plain text. A pasted media link `javascript:` or `data:text/html` is refused. Test: Task 8, `coller : texte brut, liens dangereux refusés`.
4. **Conflict:** publishing after another device published offers « Recharger » or « Écraser ». Neither path loses the draft without confirmation. Test: Task 7, `publier : conflit`.
5. **Protected files:** a protected folder never exposes a Drive URL or thumbnail in public listings. A refused key forces the password again. Test: Task 10, `dossier protégé : clé refusée → mot de passe redemandé`.

### Task 2: Media rendering and auto framing

**Interfaces:**
- Produces: `typeMedia(m: {url,type?}|string|null) -> 'image'|'video'|'youtube'|null` in `model.js`.
- Produces: `idYoutube(url) -> string|null` in `model.js`.
- Produces: `visuel(media, { repli: () => Node, classe?: string, prioritaire?: boolean }) -> HTMLElement` in `media.js`. It returns `span.visuel` holding:
  - an `img` (lazy, async decoding; `fetchpriority=high` when `prioritaire`);
  - or a `video[muted][loop][playsinline]`, with `autoplay` unless reduced motion;
  - or a YouTube thumbnail `img` plus `span.lecture`.
  - It sets `data-cadrage="cover|contain"` after metadata load. `contain` adds `span.flou` behind, using the same source.
  - On error it is replaced by `repli()`.

  - an explicit `type` wins;
  - `typeMedia(null)` → `null`;
